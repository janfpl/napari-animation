# Development notes

Working records from the development of the 3D scene, section-rendering and
export features: implementation plans, code-review rounds, performance
investigations and the raw benchmark results behind them.

They are kept for history and are not user documentation; see the parent
[`docs`](..) folder for that. They describe the code at the time they were
written, so file names, line references and test counts may be out of date.
Some notes cite local datasets or log files that are not part of this
repository. The scripts that produced the benchmark results are in
[`benchmarks`](../../benchmarks).
